# 主窗口

> 本文介绍主窗口的标题栏按钮和左侧导航栏的使用方式。

[//]: # (@section: titlebar)
## 标题栏

主窗口顶部是自定义标题栏，从左到右依次为：

- **应用图标**：显示应用 Logo。
- **应用名称**：显示"自动点名"。
- **置顶按钮**：点击切换窗口置顶状态。激活后按钮高亮，窗口始终显示在最前方；再次点击取消置顶。
- **GitHub 链接**：点击后在系统浏览器中打开 [项目 GitHub 主页](https://github.com/bytecascade-Lee/rollcaller) 。
- **窗口控制**：
  - **最小化**：将窗口最小化到任务栏。
  - **最大化/还原**：点击切换窗口最大化与还原状态。鼠标悬停可触发 Windows 11 贴靠布局（Snap Layout），方便多窗口分屏。
  - **关闭**：关闭应用窗口。

[//]: # (@section: sidebar)
## 左侧导航栏

主窗口左侧为导航栏，提供四个页面的快速切换：

- **自动点名**：进入点名页面，执行单次或连续点名。
- **学生管理**：进入学生管理页面，添加、编辑、删除、导入、导出学生。
- **历史记录**：进入历史记录页面，查看和管理所有点名考勤记录。
- **帮助文档**：打开独立的帮助窗口，查看应用帮助文档。

点击任一导航项即可切换到对应页面，当前激活的页面会在导航栏中高亮显示。
