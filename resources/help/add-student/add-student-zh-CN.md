# 添加学生

当学生数量不多，或需要临时补充个别学生时，可以直接逐个添加。每个学生包含两个关键信息： **学号**和 **姓名**。

## 操作步骤

1. 点击左侧导航栏进入「学生管理」页面。
2. 点击工具栏中的「添加」按钮，弹出添加学生对话框。
3. 填写以下信息：
    - **学号**：学生的唯一编号（必填）。
    - **姓名**：学生的姓名（必填）。
4. 点击「确定」保存。

## 添加结果

系统会根据学号、姓名与已有记录是否匹配，返回不同的结果：

- **直接添加**：该学号和姓名没有记录，学生直接添加成功。
- **自动恢复**：该学号对应一条已被删除的记录，且姓名完全一致，系统会自动将其恢复为活跃状态。
- **覆盖或保留**：该学号对应一条已被删除的记录，但姓名不同。系统会让你选择：
    - **覆盖**：用新信息替换原记录。
    - **保留**：保留原有记录，本次不添加。
- **拒绝添加**：该学号对应一条仍处于活跃状态（未被删除）的学生记录。为避免冲突，系统不允许重复添加，需先处理该学生（例如删除）后再试。

## 关键说明

- **学号和姓名必填**：未填完整时「确定」按钮会处于禁用状态。
- **搜索定位**：添加完成后，可在页面顶部搜索框中按学号或姓名快速找到该学生。
- **批量添加**：如果学生数量较多，推荐使用[批量导入学生](../batch-import/batch-import-zh-CN.md)一次性导入。
