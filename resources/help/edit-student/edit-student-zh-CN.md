# 修改学生信息

当学生的学号或姓名发生变更时，可以随时修改。应用会实时检测学号是否与其他学生重复，确保学号始终唯一。

## 操作步骤

1. 点击左侧导航栏进入「学生管理」页面。
2. 在列表中找到目标学生（可使用顶部搜索框按学号或姓名快速定位）。
3. 点击该学生所在行对应的「编辑」按钮，弹出编辑对话框，原有数据会自动填充。
4. 修改 **学号**或 **姓名**。
5. 点击「确定」保存修改。

## 关键说明

- **学号冲突提示**：如果填写的学号已被其他学生占用，会显示清晰的冲突提示，此时无法保存。
- **必填项**：学号和姓名都不能为空，未填完整时「确定」按钮处于禁用状态。

## 常见疑问

- **能只改姓名、不改学号吗？** 可以，两者独立编辑，未改动的字段保持不变。
- **修改后什么时候生效？** 点击「确定」保存后立即生效，后续点名和历史记录都会显示最新信息。
