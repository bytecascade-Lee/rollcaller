# 批量导入学生

如果班级人数较多，或者你已有一份现成的 Excel 学生名单，可以使用批量导入功能，一次性将全部学生加入应用，省去逐个添加的麻烦。

导入采用 **三步向导**流程，每一步都有清晰指引。

## 准备 Excel 文件

准备一份包含 **学号和姓名两列数据**的 Excel 文件即可。

## 导入步骤

### 步骤一：选择文件

1. 在「学生管理」页面点击「导入」按钮，进入导入向导。
2. 点击选择你准备好的 Excel 文件。
3. 系统会读取并预览文件中的数据。

### 步骤二：配置表头行数及列映射

这一步告诉应用文件中表头行数有哪些，哪一列是学号、哪一列是姓名：

- **表头行数**：通过表格左侧冻结列内的拖拽箭头，将箭头指向某一行，即可忽略该行及之前的所有行（通常用于跳过标题行）。箭头指向表头表示不忽略任何行。
- **列映射**：为"学号"和"姓名"分别指定对应的数据列，确保数据对应正确。

配置变更后，之前对数据的处理决策会自动清空，需要重新确认。

### 步骤三：导入与冲突处理

1. 系统会预览解析结果，并 **自动检测数据冲突**。
2. 对于存在冲突的数据，需要你做出处理决策：
    - **覆盖**：用导入的数据替换现有学生。
    - **跳过**：忽略该条导入数据。
    - **保留**：保留现有学生，不导入该条。
3. 处理完所有冲突后，点击「导入」完成导入。若仍有未决策的冲突，按钮会显示"导入（x/y 已决策）"，需先完成决策。

## 关键说明

- **冲突必须处理完才能导入**：存在未决策的冲突时无法执行导入，避免误操作。
- **列映射或表头行数改动后**，已做的冲突决策会被清空，请重新确认。
- 学生数量较少、不想准备 Excel 时，也可以直接[添加学生](../add-student/add-student-zh-CN.md)。
