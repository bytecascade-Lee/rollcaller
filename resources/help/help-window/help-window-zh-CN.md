# 帮助窗口

> 本文介绍帮助窗口的标题栏功能、树形导航和全文搜索。

帮助窗口是一个独立窗口，用于查看应用的帮助文档和项目文档。点击主窗口左侧导航栏中的「帮助」按钮即可打开。

[//]: # (@section: titlebar)
## 标题栏

帮助窗口标题栏从左到右依次为：

- **应用图标**：显示应用 Logo。
- **标题**：显示"帮助文档"。
- **前进/后退**：浏览历史导航。在帮助文档中点击链接跳转后，可通过这两个按钮返回上一页或前进到下一页。当没有可前进/后退的历史时，按钮自动禁用。
- **搜索**：点击打开全文搜索弹层。输入关键词后实时搜索所有帮助文档，结果高亮显示关键词。支持键盘导航：↑/↓ 移动选中、Enter 打开、Escape 关闭。再次点击搜索按钮关闭弹层。
- **主界面**：点击快速跳回主应用窗口。
- **GitHub 链接**：点击后在系统浏览器中打开 [项目 GitHub 主页](https://github.com/bytecascade-Lee/rollcaller) 。
- **窗口控制**：
    - **最小化**：将窗口最小化到任务栏。
    - **最大化/还原**：点击切换窗口最大化与还原状态。鼠标悬停可触发 Windows 11 贴靠布局（Snap Layout），方便多窗口分屏。
    - **关闭**：关闭应用窗口。

## 树形导航

窗口左侧为树形目录导航，按功能模块组织文档结构：

- 点击节点展开/折叠子节点。
- 点击叶子节点在右侧查看对应文档。
- 点击外部链接（如项目文档中的链接）会在系统浏览器中打开。
- 文档内容切换后自动滚动到顶部；通过锚点链接跳转时平滑滚动到目标位置。
